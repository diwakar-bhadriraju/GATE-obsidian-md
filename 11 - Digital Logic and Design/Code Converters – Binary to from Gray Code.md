# Code Converters - Binary to/from Gray Code

In this article, we will go through Code Converters - Binary to/from Gray Code, we will start our article by defining Code converters, Binary code and Gray code, and then we will go through the conversion of binary code to gray code and vice versa.
## What are Code Converters?
Code Converters are the [digital circuits](https://www.geeksforgeeks.org/digital-logic/what-is-digital-logic/) or algorithms that are designed to translate data representation from one format to the other format. In this article, we will go through binary to gray code converters. The binary-to-Gray code converter takes binary input and translates it to its corresponding gray code representation.
For more about conversions please go through [Number System and base conversions](https://www.geeksforgeeks.org/digital-logic/number-system-and-base-conversions/).
## What is a Binary Code?
The Binary code is the numerical system used in digital electronics. It only consists of two Symbols which are 0 and 1. In [binary code](https://www.geeksforgeeks.org/dsa/bcd-or-binary-coded-decimal/) each digit is represented by power of 2 with the starting bit (right most bit) as 20 and bit as 21 and so on. The binary code is serves as the basis for encoding text, number and various other types of data in the digital devices.
## What is a Gray Code?
[Gray Code](https://www.geeksforgeeks.org/digital-logic/what-is-gray-code/) system is a binary number system in which every successive pair of numbers differs by only one bit. It is used in applications in which the normal sequence of binary numbers generated by the hardware, is read while the system changes from the initial state to the final state. This could have serious consequences for the machine using the information. The Gray code eliminates this problem since only one bit changes its value during any transition between two numbers.
**Another Name of Gray Code**
- Unity Hamming Distance Code
- Cyclic Code
- Reflecting Code
## Converting Binary to Gray Code
Let b0, b1, b2 and b3 be the bits representing the binary numbers, where b0 is the LSB and b3 is the MSB, and Let g0, g1, g2, and g3 be the bits representing the gray code of the binary numbers, where g0 is the LSB and g3 is the MSB.
The [truth table](https://www.geeksforgeeks.org/electronics-engineering/truth-table/) for the conversion is

| 1001 | 1101 |

> gn = bn

## Converting Gray Code to Binary
Converting gray code back to binary can be done in a similar manner. Let b0, b1, b2 and b3 be the bits representing the binary numbers, where b0 is the LSB and b3 is the MSB, and Let g0, g1, g2, and g3 be the bits representing the gray code of the binary numbers, where g0 is the LSB and g3 is the MSB.

## Application of Code Converters - Binary to/from Gray Code
Given Below are the Applications of the Code Converters - Binary to/from Gray Code
- **Rotary Encoders:** The Rotary [encoders](https://www.geeksforgeeks.org/digital-logic/encoder-in-digital-logic/) are device which is used to convey rotary motions into digital signals. The code converters use to convert the gray code output of rotary encodes into binary.
- **Control Systems:** The Gray code converters are used in the [Control system](https://www.geeksforgeeks.org/electronics-engineering/control-system/) to integrate between system using binary and gray code.
- **Signal Processing:** The Code converters are used in the [signal processing](https://www.geeksforgeeks.org/electronics-engineering/what-is-digital-signal-processing/) to translate between binary and gray coded signals.
- **Analog-to-Digital Conversion:** The code converters are used in ADC to interface between gray coded [ADC](https://www.geeksforgeeks.org/digital-logic/analog-to-digital-conversion/) outputs and binary based systems.
